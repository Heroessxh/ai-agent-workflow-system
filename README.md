# Personal AI Agent Workflow System

## Project Overview

This project is a lightweight AI Agent workflow system designed to improve long-term task execution, structured planning, and knowledge organization.

The system focuses on solving several common problems:

- Information fragmentation
- Repetitive manual organization
- Difficulty maintaining long-term project execution
- Long-context conversation management

Instead of using AI only for simple Q&A, this workflow attempts to build a continuous execution loop with context memory and structured reasoning.

---

## Core Workflow

### 1. Input Analysis

AI analyzes raw input and extracts key objectives.

### 2. Task Decomposition

Complex goals are split into executable subtasks.

### 3. Structured Planning

The workflow generates:

- priorities
- execution paths
- risk reminders
- next-step actions

### 4. Long-Context Tracking

Historical context is continuously referenced to avoid losing important information during long conversations.

### 5. Human Verification

Final outputs are manually reviewed to ensure reliability.

---

## Multi-Agent Logic

The project experiments with lightweight multi-agent collaboration:

- Planning Agent
- Documentation Agent
- Review Agent
- Execution Tracking Agent

Each agent handles different responsibilities to reduce reasoning confusion and improve workflow stability.

---

## Knowledge Base Module

The workflow also includes a lightweight AI knowledge management module.

Core capabilities include:

- automatic summarization
- markdown generation
- knowledge classification
- long-term note organization
- context linking
